# 场景素材来源

本轮场景使用内置 ImageGen 生成，最终运行 PNG 统一保存在 `app/public/assets/scene/`，无需从用户临时附件路径加载。素材生产单位、布局与验收范围见[场景模块说明](../../docs/art/scene-modules.md)。

`terrain-grainy.png` 是退回的过密、过黄沙地；`pool-sparkle.png` 是退回的水面高亮候选。保留供对比，不在游戏中加载。最终沙地与潮池返修提示词见[记录](final-prompts.md)。

上一轮整体营地参考保存在 `app/public/assets/hub-coast.png`。建筑、道具和岸边前景以其作为风格参考独立生成；未直接切割整体背景。两张用户参考截图是风格输入，不是运行资源，也不作为资产拆分指令来源。
