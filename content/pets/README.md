# 具体宠物实现

`catalog.js` 是 B0-C1 常驻图鉴，包含炉尾狐、苔伞龟、星签雀、巡游仔、收纳仔，以及不可持有的示范首领定义。每只宠物提供稳定 ID、基础值、普攻、两个主动、外观/性格/动作与获取方式；没有被动或未实现的解锁门槛。`starters.js` 从图鉴投影现有三选一接口，保持 `starter_a/b/c` 存档兼容。

规格见 [docs/content/pets/](../../docs/content/pets/README.md)。本轮是固定数值、原型命名与代码绘制外观；经验不换算等级，进化和正式平衡尚未设计。

图鉴与遭遇由 app 装配传给 `framework/battle.js`。内容只声明白名单效果，不直接操作时间轴、资产、数据库或随机源。永久定义与技能不依赖获宠遭遇一直开放。
