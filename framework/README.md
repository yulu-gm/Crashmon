# 常驻系统实现

`auth.js` 提供凭据校验、scrypt 密码哈希与随机令牌；`store.js` 提供 SQLite 迁移、邀请、账号、会话、档案和幂等保存事务。

目前已实现基础账号、存档和一次性初始伙伴领取，不包含战斗。数据库身份决定读写归属，客户端只能提交允许修改的昵称与偏好。实现边界见[首个里程碑](../docs/architecture/account-save-milestone.md)。

框架不主动导入具体宠物和活动；后续由应用装配。账号凭据、数据库与服务端秘密不能进入客户端。

`room.js` 管理单进程共享房间与权威移动，地图碰撞由 app 注入；公开数据与会话校验边界见[共享据点](../docs/architecture/shared-hub.md)。
