# Crashmon 伙伴素材生产

先确认这次需要的伙伴与动作，读取项目的具体伙伴设计、表现资源清单和渲染入口。已有外观只在用户请求范围内修改；物种 ID、永久宠物 ID、技能数值和存档不随美术制作变化。

## 制作与接入

1. **身份规格。** 从设计提取体型、色块、肢体数、尾巴、装饰和不对称物件。新角色先生成透明标准图；已有角色以保存的标准图为身份参考。若设计有歧义但不影响当前制作，记录候选假设后推进。
2. **标准视图。** 地图使用正、背、左右四个真实视角。提示词明确各槽位置、全身留白、落脚基准和固定识别物。不用旋转正面图代替侧面；侧挎包、文字等不对称结构不能靠镜像保持身份。
3. **动作图集。** 用内置 ImageGen，引用本地标准图，一次生成完整短序列或关键姿势图集，避免逐帧独立重画。动作可用“待机 → 蓄势 → 攻击/辅助姿势 → 恢复”的时间轴；普攻与强攻可共用身体姿势，通过位移、节奏和效果区分。只有当前动作确实需要时才补帧。使用前先查看引用的本地图片。
4. **检查透明度与切格。** 执行 `node <本技能目录>/scripts/sprite-inspect.mjs <图.png> <列数> <行数>`。脚本只读 PNG，输出每格非透明包围盒、边界像素与每行的实际透明分隔 `rowGaps`。透明预览出现色晕不等于 PNG 有实色背景，先查 alpha。若身体跨等分边界，在实际空白分隔内选择边界，记录显式 `rects`；若两个身体真的相交或源图已截断，返修图像。不要把越界图直接四等分。
5. **校准。** 整段动作共享像素比例；不等宽矩形需要共享 `referenceHeight`。人工确认脚底/骨盆锚点，保留跳跃或前倾的有意偏移。不按每帧非透明包围盒自动缩放、居中或对齐最下面的像素。检查头身大小、脚底、装饰、恢复到待机的跳变。
6. **接入。** 将选用 PNG 保存到项目，把资源 ID、视图、采样矩形、锚点、时长、动作 ID 映射写入清单。命中、护盾、标记与身体图分开。客户端只排演已结算事件，不计算战斗结果。同一版本的 UI 重绘继续原时间轴，新的行动版本才重置。
7. **验收。** 检查放大、实际尺寸、左右、暂停逐姿势、地图待机、手机、最大队形及减少动态效果。Canvas 必须截图查看。确认首次加载后卡片会重绘，隐藏页面/关闭战斗会停止无用播放。机械校验通过不能替代外观确认。

## Crashmon 项目约定

在 Crashmon 工作时读取 [资源契约](references/crashmon-contract.md)，按既有入口接入。运行 `npm run art:check` 检查真实 PNG 与技能覆盖，`npm run check` 检查语法；有裁切或时间轴行为修复时增加针对回归的测试。纯配色、静态版式不额外制造测试。

## 交付

保存最终图、最终提示词及返修提示、资源元数据、实际检查结果和待评审限制。说明每个动作的制作形式（关键姿势加时间轴或完整帧动画）。生成式绘图不能保证一次就有一致解剖与切格，稳定性来自固定身份参考、人工校准、确定性检查与游戏内验收。不要因素材候选可用就宣称商业量产质量或美术已经 Approved。
