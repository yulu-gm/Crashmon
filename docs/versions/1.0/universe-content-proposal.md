# 1.0 宇宙探索首章：内容与表现提案

更新日期：2026-09-25。状态：Draft；以下名字、地图、种族、故事、时长和奖励均是候选方案，不是已冻结的生产清单。本轮只归档，不改现有伙伴、共享据点或存档。

上级：[1.0 大纲](outline.md)。规则流程：[首次体验](../../game-design/first-session.md)。视觉正文：[美术与表达方向](../../game-design/art-direction-v1.md)。

## 1. 与已确认方向的关系

已确认的题材方向是宇宙探索，“抽象”指有梗、幽默。画面参考用户提供的细线、柔和配色、巨型机械与遗迹插画；不是几何抽象，不默认全 3D，也不再以高饱和太空塑料感作为主方向。

保留“控制主角 → NPC 领伙伴 → 探索捕捉 → 双宠配合 → 区域挑战 → 成长”的首次体验。首章是长期可用的入门冒险，不是结束后撤掉、让新玩家无处入门的限时活动。

本提案提供能串起角色、地图和玩法的一个主题供继续设计，不要求立刻锁定它。正式确认后，单只宠物与具体区域的详细设计分别进入 docs/content/，本文件改为引用，不按版本复制多套规格。

## 2. 核心设定与故事

玩家是一名边缘星区的新调查员，与 Crashmon 组成搭档，记录当地生物并处理科考站遇到的小麻烦。调查站总体可靠，人员和设备各有怪习惯；幽默不建立在所有角色都无能上。

候选章名：《首航：请勿叼走导航设备》。候选星球名：磁屿星。

野外观测点的一段导航天线失踪。玩家选择伙伴、沿途结识野生 Crashmon，发现它们会把人类零件用于生活，最终找到把天线带回巢里的大型磁性生物。取回关键设备、给它留下废弃材料后，远处恢复了新星球的信号。

危机局部而明确，不从第一版开始拯救宇宙。结尾既有一个温暖的小笑点，也有真正的远方与下次出发的期待。

## 3. 地图：一颗星球，不做互不相干的景点合集

建议以干燥台地与下方潮光水域构成同一颗星球的空间关系。原先“天线草甸”等称呼是功能占位，本轮可用更符合参考图的地貌包装；具体名称仍待定。暖色室外和冷色遗迹共用岩层、旧漆、设备语言与当地生态，不是强行增加两颗星球。

| 区域 | 体验职责 | 视觉记忆点 | 制作边界 |
| --- | --- | --- | --- |
| 停泊调查站 | 领伙伴、恢复、出发与相遇 | 沙海中的旧式科考船，甲板和船旁有生活痕迹 | 首版静态停泊，不做驾驶或移动载具同步 |
| 风蚀台地 | 观察目标、首次战斗与捕捉 | 奶油岩面、灰蓝阴影，野生生物收集落下的零件 | 小主路加两条汇合支路，不靠面积制造探索量 |
| 旧观测场 | 双宠配合、发现设备去向 | 机械残件嵌进地貌，某些看似零件的东西会自己走动 | 复用台地资源，主要变化来自互动与遭遇 |
| 潮光巢穴 | 区域挑战与收尾 | 青绿水域、浅色遗迹，巨大安静的构造物与小生物共存 | 深水和大遗迹可先作背景，不自动引入游泳、潜水与复杂照明 |

参考图的巨型载具和巨像不直接复制。原创地图需要自己的轮廓、结构与互动布局。首次内容预算紧张时，旧观测场可作为台地的一段，潮光巢穴缩为一个挑战房间。

## 4. 五个体验段落

| 段落 | 玩家实际操作 | 表现与幽默 | 对应原流程 |
| --- | --- | --- | --- |
| 报到 | 自由走近 NPC，比较 A/B/C 并最终领取 | 三只各有一个短小待机性格；“可靠，是它们自己填的”可作台词候选 | 选择与一次性领宠 |
| 观察 | 从两类可见野生目标中选择一个，战斗并捕捉 | 生物先以习性吸引注意，捕获后仍保留自己的小物件 | 首战与教学捕捉 |
| 调查 | 进入观测场，进行第一场双宠战斗 | 生活习性解释技能作用，不只增加第二个攻击按钮 | 小队协作 |
| 找到巢穴 | 应对区域首领，读懂蓄力和破绽 | 对方并非恶人，只认为吸得过来的东西都属于自己 | 挑战与重试 |
| 重新出发 | 取回设备、记录发现、获得成长线索 | 安静看远处星光，结尾保留一句短笑话，不持续打断氛围 | 成长与后续目标 |

通信可以减少反复回据点交任务，但不由此引入复杂远程任务平台。任务、提示与演出按已有确认状态恢复，不靠客户端点完对话就永久发奖。

## 5. 第一批伙伴：让性格、生态和能力相连

以下约六个基础种族只是容量参考。已有 A/B/C 的三选一与一次性领取继续有效；正式种族映射需确认，不直接改稳定 ID、不给旧账号重新抽取或额外发放。

| 现有位置或用途 | 候选名称 | 可观察的特点 | 玩法方向，不是技能定案 |
| --- | --- | --- | --- |
| 初始 A | 喷嚏龙 | 装凶、憋喷嚏，喷火后自己也后退一下 | 直接输出，独立作战可靠 |
| 初始 B | 窝窝甲 | 怕生，仍愿意抱着盖板站到队友前面 | 防护与保护，同时具备正常攻击 |
| 初始 C | 天线狐 | 耳朵像天线，总显得知道更多消息 | 标记或削弱，单宠阶段也可推进 |
| 初次捕获候选 | 电啾 | 找旧设备蹭电，充完电羽毛炸开 | 简单攻击与支持，可搭配不同初始选择 |
| 初次捕获候选 | 借壳蟹 | 把不合尺寸的零件坚持当成家 | 防护或削弱，提供另一种配队理由 |
| 后段发现 | 磁团仔 | 身上挂满顺路吸来的杂物 | 防护与进攻的联系，呼应本地生态 |

首领“磁老大”可作为同一生态中的大型个体提案，但不在未确认前等同磁团仔的进化形态，也不自动承诺可捕获。捕获来源、首领奖励和复战规则需要独立设计。

进化强化原本个性。例如窝窝甲从躲在盖板后面，变成主动替队友举盾；不要只放大体型或突然换成不相关的帅兽。约六个种族不等于六张图片，不预先承诺每只三阶段进化与全方向动画。

## 6. 首领与成长边界

磁老大的候选循环是：用零件形成护盾 → 明确提示蓄力 → 执行一次攻击 → 零件散落、露出破绽。先验证这个循环能否让合法双宠组合做出选择，不增加偷取永久装备、物理吸附、场景破坏或时空回溯等额外系统。

所有初始选择及教学捕获组合都需要试玩；辅助开局不能软锁，挑战不要求唯一正确阵容。新手失败与捕捉保护继续引用首次体验和数据规则，不因喜剧包装隐瞒概率、消耗或恢复结果。

成长至少让玩家感知一项能力变化。首次进化目标保留为首个完整区域章节内可达，条件和具体对象待确认；不要求先等待多天才能验证进化体验。

## 7. 多人与活动如何接入

共享据点已经存在，继续作为玩家见面与展示伙伴的空间。本提案不改变当前多人实现，也不把单人故事流程误报为同场合作战斗。

失踪设备属于野外观测点的个人调查进度。某位玩家完成任务，不应突然替其他玩家领奖或跳过剧情；公共据点基础服务不随个人任务状态失效。野外玩家可见范围、遭遇归属和合作战斗模式仍需另行确定。

第一章故事闭环与基本获宠途径长期保留。后续活动可以通过来访调查员、临时航线或同一生态中的新异常接入，也可以独立下线；不要为了验证热插拔而让入门关卡依赖限时活动。

一个新版本不一定是一颗新星球。先允许旧区域新增少量遭遇和一个完整事件，减少每版重新制作整套场景的压力；新机制和永久宠物各自带来的长期维护成本单独评估。

## 8. 精致度预算与下一步

建议以一个小据点、三段紧凑探索、两三位必要 NPC、少量伙伴和一个首领构成完整短篇。前 20–30 分钟验证入门；完整首章约 60–90 分钟仅是本轮节奏假设，不是已测时长或必须填满的任务数量。

精致度优先投入同一特点的重复呼应：首次见面的动作、野外习性、战斗能力、图鉴记录和进化变化。宁可少几只伙伴，也不把所有细节放在无法交互的背景或长对话中。

下一步先确认首章方案与一张据点视觉样张，再为初始伙伴和首战写具体设计。正式资源产出遵循[美术方向](../../game-design/art-direction-v1.md)的分层、来源和可读性验收；战斗规则回到[核心玩法](../../game-design/core-rules.md)，不在这里先行实现。
