2026-10-05。实现状态：本地营地与免登录检查页已接入。美术状态：参考图方向的候选素材，等待外观反馈。

本轮依据用户“继续做场景优化”的请求，把先前整张插画替换为区域地面与独立物件。保留既有 Node / 原生 Canvas 实现，未新增引擎、地图编辑器或运行依赖。

## 使用与资源

启动 `npm start` 后访问 `/scene-lab`，无需账号。可以移动主角，切换到研究站／飞船前后和岸边，显示逻辑碰撞与图片边界，并关闭水面、灯光或启用减少动态效果。此页只展示，不连接多人房间、不写玩家存档。

登录后的营地共用同一套场景渲染器。右上角小地图缓存静态场景，实时叠加引导员、本人朝向与其他在线玩家；手机上隐藏小地图，为移动视野留出空间。

## 布局与层次

`scene-layout.js` 集中定义稳定 ID、资源路径、图集格数、取样范围、显示矩形、落脚排序点与地标文字。建筑以 `app/shared/hub-map.js` 的原障碍位置为布局依据；沿海岩石与灯柱对应原有圆形障碍。建筑范围内补少量箱子、路牌，边缘前景不增加逻辑障碍。

`scene-renderer.js` 只处理加载和画面：地面／潮池 → 地面阴影 → 建筑、道具、人物按地面纵坐标排序 → 前景。角色经过建筑后方时，重叠部分被主体遮挡；来到前方时在主体前绘制。前景带单独保持在角色之上。波纹与灯光可以分别通过效果选项关闭；减少动态效果时保持静态。

这轮以整座地标处理外部遮挡，未实现可进入的室内、局部屋檐、可开门状态或动态屏幕。原碰撞仍是矩形与圆形近似，不代表生成图片每一段轮廓都已成为精确碰撞。素材缩放、取样和锚点不会改变行走、服务器位置、NPC 交互范围或出生点。

## 制作方式与提示词

使用内置 ImageGen。前一轮 `hub-coast.png` 作为整体画风参考；沙地和潮池返修直接引用用户提供的营地参考图，以减少金黄色颗粒和强烈水面亮纹。

共用制作约束：细密不规则墨线、水彩／不透明水彩、奶油白与锈红金属、蓝灰岩石与少量粉蓝珊瑚、俯视三分之四视角、完整轮廓；透明物件不生成地面、角色、UI 或投影。各资产分别生成，未把不同生产单位合成同一张大图。

各独立生成提示词组的主体要求：

1. 飞船：单独的完整长形科幻飞船，奶油白外壳、锈红色带、07、完整支脚；透明背景，保留宽长比例。
2. 研究站：完整圆顶营地调查站、闭合正门、管线和小窗，行星标志与 CRASHMON；透明背景，无附属地面。
3. 补给棚：赭黄色遮雨棚、立柱和一组旧物资箱，结构完整；透明背景。
4. 营地门：封闭的废旧金属营地门与行星旗，整体地标；透明背景。
5. 初版潮池：单独低岩石围边浅水潮池，宽长比例；透明背景。最终用下述返修替换。
6. 道具图集：统一比例与落脚基准的 3 列 2 行独立物件，依次为岩石、珊瑚、碎石、箱子、灯柱、无文字路牌；格间留空，透明背景。
7. 岸边带：3:1 宽幅蓝灰碎岩、废弃金属与蓝粉珊瑚前景，低边缘组合；透明背景，无地面平面、建筑、角色或文字。

沙地与潮池的最终返修提示词原文见[提示词记录](../../art-source/scene/final-prompts.md)。
