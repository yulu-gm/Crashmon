# 赤沙海岸画面更新

2026-10-03，按用户提供的营地与战斗参考图更新现有二维据点。当前交付为营地美术、角色与界面，不代表战斗已实现。

## 素材与生成

使用内置 ImageGen，以用户两张参考图作为风格输入，新增：

- `app/public/assets/hub-coast.png`：手绘沙海营地背景。
- `app/public/assets/expedition-sprites.png`：透明 3×2 图集；上排火焰伙伴、岩龟、鸟，下排宇航员、引导员、调查机器人。机器人为预留美术，当前未装配为伙伴。

背景提示词：制作 CRASHMON 二维浏览器游戏背景，参考图的墨线、水彩纸纹、旧航天器、浅金沙地、蓝灰岩石与珊瑚、铁锈红涂装；3:2 俯视画面，无界面、角色或文字。中央沙地留空；左上休息飞船、右上研究站、左下潮池、右下补给棚、上方关闭出口，建筑位置以既有 960×640 地图比例约束。

角色提示词：制作真正透明背景的六角色图集，严格三列两行，完整身体、独立单元、统一脚底基线；与参考图墨线水彩风格一致。火焰蜥蜴、苔藓岩龟、鸟类伙伴、背向宇航员、正面引导员、浮空调查机器人；无标签、边框、场景与阴影。

角色由 Canvas 按图集区域绘制，保留原有宠物定义 ID、三选一领取、服务器移动和存档。面板使用深蓝灰半透明底、浅色细边、暖金提示与薄荷色状态线。桌面地图覆盖视口，窄屏跟随角色。

这次初版背景采用单层插画，建筑轮廓与旧矩形碰撞不是逐像素匹配，也没有建筑前景遮挡层；中央通路与交谈流程经过浏览器验证。后续实现见本文末尾链接。
