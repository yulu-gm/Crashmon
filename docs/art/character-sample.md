# 第一轮角色动画样本

2026-10-05。实现状态：本地样本已接入；美术状态：候选，尚未经人类外观和动作品质批准。

2026-10-06 后续：新增四只伙伴与本地战斗接入、火焰待机和攻击采样修复见[伙伴生产流程](creature-pipeline.md)。以下保留第一轮范围和历史验收。

用户在上一轮整张营地背景之后提供了素材生产方案，要求先验证主角与一只 Crashmon 的角色动作，再推进可独立修改的区域。本轮按该顺序实施，没有一次生成整批宠物或重建引擎。

## 交付与使用

启动既有本地服务后访问 `/animation-lab`，无需登录。检查台支持角色、朝向、动作、播放速度、暂停、逐帧、画布边界与落脚点；同时显示实际游戏尺寸，以及可移动、可碰撞、可经过物件后方的简单沙地样本。

| 样本 | 已实现表现 | 资源位置 |
| --- | --- | --- |
| 宇航员 | 上、下、左、右静止图；各方向四帧行走 | `app/public/assets/characters/player/` |
| 火焰伙伴 starter_a | 四方向静止和四帧地图行走 | `app/public/assets/characters/flame/` |
| 火焰伙伴战斗形象 | 固定向右待机、短促撞击、憋喷嚏与恢复 | 同目录的 `tackle.png`、`sneeze.png` |
| 演出效果 | 按动作事件播放撞击闪光、嘴部扇形火焰与目标反馈 | `app/public/animation-lab.js` |

本轮采用短序列帧验证画风与接入。没有安装 Spine、地图编辑器、引擎或新运行依赖，没有承诺其他体型能直接复用这套动作。

营地主角使用四向素材。持有 starter_a 时展示转向与行走的跟随伙伴；B、C 保留此前外观，不冒用火焰伙伴的动作。其他玩家也使用同一套四向主角表现，身份、昵称与服务器权威位置保持原逻辑。

## 资源约束

`character-assets.js` 是资源清单，保存稳定资源 ID、参考图、方向、显示高度、锚点、整段比例、原点、步长、帧时长、事件与嘴部挂点；`character-motion.js` 只处理位移到步态的映射；`character-renderer.js` 负责图集播放。动作不写入存档，不决定宠物属性或战斗结果。

- 不使用正面图旋转成侧面，也不在运行时镜像左右。
- 每段动作共享一份比例。人工校准骨盆与落脚原点，保留动作局部偏移；不逐帧自动居中或缩放。
- 行走按实际位移累计，停止、顶住障碍物时回到待机。四向边界保留一定朝向，避免微小位置修正使角色反复转身。
- 大位置跳跃与过长帧间隔不累计脚步。重新加入房间重置表现状态。
- 减少动态效果偏好启用时，营地主角与跟随伙伴使用对应方向静止图。
- 地图与战斗有不同资源入口。普通营地只载入地图图集；攻击素材在检查台载入。
- 简单检查区的出生点与碰撞在 `animation-lab-map.js`，与图像独立。原营地共享碰撞文件未改动。

## 制作提示词

方式：内置 ImageGen。每次派生引用项目内已保存参考图，不把角色重新当成纯文字创作。最终提示词组如下，方向和动作各自单独生成：

1. 标准图：以原宇航员或火焰伙伴为参考，制作透明 2×2 四方向静止图；保持头身比例、衣服分色、背包／双足双臂单尾结构；实际正面、背面、左右侧面；统一画布与落脚基准，不加标签、阴影或场景。
2. 地图行走：引用标准图，一次生成一个方向、横排四个完整姿势；前进脚、过脚、另一只脚前进、过脚；相反手臂摆动；保持体型、色彩与朝向一致，不把第一接触姿势重复成第三姿势；透明画布，不加场景、网格或文字。
3. 正面返修：只修改横排第三帧的下肢与手臂摆动，让画面右侧靴子抬起、左侧靴子落地，成为第一帧的相反脚步；保持其余帧、躯干位置、尺寸和透明背景。
4. 普通撞击：引用火焰伙伴标准图，固定向右，四个身体关键姿势为后缩蓄势、腿部蹬地前倾、伸展扑击、直立恢复；保持身体比例与原画布，不生成命中特效。
5. 特色喷嚏：同一角色固定向右，四个姿势为鼓腮吸气、仰头憋喷嚏、闭眼张嘴前倾、疲惫恢复；保留尾端火焰，嘴部喷火效果由运行时单独绘制，不烘焙进身体帧。

原始标准参考及退回候选保存在 `art-source/characters/`，可播放图集保存在上述项目素材路径。当前关键帧仍可能有轮廓和纹理轻微变化；四帧循环能验证流程，不等于已具备商业量产动作质量。

## 验证

`npm run check` 通过；`npm test` 共 21 项通过，其中新增 3 项只覆盖实际位移、撞墙停止、帧率独立、网络跳跃与方向边界等有行为风险的逻辑，没有为颜色与静态面板增加测试。

使用独立临时数据库，浏览器实际验证：注册与登录 → 点击靠近引导员 → E 交谈 → 领取 starter_a → 转向和移动 → 伙伴跟随 → 刷新恢复原宠物 ID。检查台验证素材载入、方向选择、两种动作、停止及顶住障碍物。1360×900／1050 与 390×844 截图检查，无脚本错误与横向溢出。未修改已有玩家数据或部署。
