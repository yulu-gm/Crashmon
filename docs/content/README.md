# 具体内容设计

[宠物](pets/README.md)与[活动](activities/README.md)各维护一份规格，由[版本大纲](../versions/README.md)引用。B0-C1 已补齐五只宠物的原型规格与[教学、双宠、四对四及示范首领遭遇](encounters/b0-encounters.md)，均为未实现、待试玩草稿，不是冻结的正式内容名单。

按稳定 ID 对应设计、实现与素材；现有 `starter_a/b/c` 保持不变，新候选沿用小写下划线风格，不因文档整理迁移身份。注册格式等待底层设计，改名不得随意改变已发布内容身份。

活动可以引用永久宠物；永久宠物不能依赖活动保持开放。这是生命周期约束，不是增加第三个顶层系统。
