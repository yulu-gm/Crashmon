# 常驻玩法设计

[首次体验](first-session.md)描述操控主角、NPC 领宠、首次捕捉、双宠协作与区域挑战。当前继续验证完整体验，同时按下述方向细化题材和美术；入门流程长期保留，不依赖限时活动。

[多单位回合制战斗策划案](battle-system.md)是战斗规则的单一正文：最多四只同时上场、速度时间轴、技能和共享资源、伤害与状态、捕捉、胜负、断线与版本边界。v0.1/B0 是明确的原型基线，含 F01–F03 场景和 B01–B30 验收，已有本地 PvE 实现和部分自动化/浏览器验证，未完成平衡或全量 B01–B30 验收；见[本轮记录](../verification/battle-2026-10-06.md)。

[美术与表达方向 v1](art-direction-v1.md)定义宇宙探索、细线色块场景、幽默伙伴、界面可读性和制作基准，并附[用户参考图与来源](references/README.md)。方向与实际素材交付状态分开；首章如何应用见[内容提案](../versions/1.0/universe-content-proposal.md)。

[核心玩法规则](core-rules.md)作为跨专题总览，链接战斗、捕捉、成长、胜负和异常情况下的玩家权益；不重复维护战斗公式。五只伙伴已有完整 B0-C1 定义；固定基础值，经验仅记账，升级进化仍需设计。

这里回答玩家如何游玩；技术执行放在 [architecture/](../architecture/README.md)，具体宠物与活动放在 [content/](../content/README.md)，版本范围放在 [versions/](../versions/README.md)。

本地可玩进展：[二维据点与初始伙伴原型](hub-prototype.md)、[战斗界面](battle-ui.md)和[战斗框架](../architecture/battle-framework.md)。遭遇卡片提供教学、普通野生与首领入口，完整野外地图和部署未完成。
