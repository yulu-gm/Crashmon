# 常驻玩法设计

[首次体验](first-session.md)描述操控主角、NPC 领宠、首次捕捉、双宠协作与区域挑战。当前继续验证完整体验，同时按下述方向细化题材和美术；入门流程长期保留，不依赖限时活动。

[美术与表达方向 v1](art-direction-v1.md)定义宇宙探索、细线色块场景、幽默伙伴、界面可读性和制作基准，并附[用户参考图与来源](references/README.md)。方向已进入设计，具体规格待样张验证，不等于现有原型已经更换美术。首章如何应用见[内容提案](../versions/1.0/universe-content-proposal.md)。

[核心玩法规则](core-rules.md)描述队伍、回合、捕捉、成长、胜负和异常情况下的玩家权益。首次体验中的角色定位、数量与节奏是原型建议，具体技能和数值仍需细化。

这里回答玩家如何游玩；技术执行放在 [architecture/](../architecture/README.md)，具体宠物与活动放在 [content/](../content/README.md)，版本范围放在 [versions/](../versions/README.md)。
