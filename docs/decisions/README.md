## 已确认方向

来源：项目发起人于 2026-09-24 的本次讨论；后续变更分别记录日期与依据。

| 方向 | 内容 |
| --- | --- |
| 定位 | 小规模多人抓宠回合制；总玩家约 10–20 人、同时在线约 5–10 人 |
| 共创 | 设计者可按版本更换；新宠物通过捕捉或活动获得，可升级进化 |
| 架构目标 | 常驻系统 + 活动插件，版本内容热插拔 |
| 分工 | 人类负责设计，Agent 负责编码与维护 |
| 名称 | Crashmon；仓库 yulu-gm/Crashmon |
| 本轮文档补充 | 账号、登录与用户数据纳入常驻系统，补充专题及 1.0 验收范围 |
| 战斗方向（2026-10-06） | 出战队伍最多 4 个单位，速度驱动行动；详细 B0 原型规则另文维护 |

总体方案整体是讨论稿，导入不等于全部批准。

## 2026-09-25：首次冒险体验归档

来源：项目发起人提出先不处理美术风格，初版体验完整后再考虑题材和画风；玩家操控主角，进入地图后在 NPC 处领取初始 Crashmon。随后确认“可以 把这部分初版流程设计放入仓库”。

本次授权限于文档更新；没有新增运行实现、测试执行、部署或正式发奖授权。玩家旅程与账号/存档的工程验收分别维护。

## 2026-09-25：多人同屏据点

用户明确要求“按照多人同屏的方式来做”。据此实现同一服务进程内共享地图、角色移动与在线状态同步，保留各自账号与伙伴归属。多人战斗形式仍待定。

本轮采用服务端权威移动、同源 HTTP 短轮询和每账号一个活跃地图连接，属于原型实施选择；没有扩大为公开部署授权。见[共享据点](../architecture/shared-hub.md)。

## 2026-09-25：宇宙探索、美术与幽默表达方向

来源：用户要求初版内容更精致，提出宇宙探索背景，并澄清“抽象”指有梗、幽默；随后提供两张沙海巨型载具、发光水域遗迹的截图，接受提炼参考的方向并明确“可以 把这套设计思路落成文档上传，可以附上参考图”。

本轮确定设计方向：世界有诗意的复古科幻旅行感，细线、柔和色块、尺度反差与生活细节；伙伴更简洁易读，通过性格、动作与能力产生幽默，不做网络表情拼贴。正式描述及制作边界见[美术方向 v1](../game-design/art-direction-v1.md)，截图来源与处理见[参考说明](../game-design/references/README.md)。

这调整了此前“先不考虑题材和画风”的阶段安排：现在允许明确方向并验证样张，但玩法原型继续推进，不默认立即量产全套美术。不改变已确认的二维共享据点、账号隔离、一次性领宠、永久资产或插件生命周期约束。

[首章内容提案](../versions/1.0/universe-content-proposal.md)中的磁屿星、调查任务、候选生物、首领、约六个种族与章节时长均是可讨论方案，配色数值与资源规格也待确认；不重命名或替换现有 A/B/C 定义 ID，不修改已有宠物实例。

本轮仅授权项目文档与参考图归档，不包含代码、美术资产替换、部署、清档或生产数据操作。第三方参考截图的真实作者与许可尚未核实，展示账号不是版权归属证明；不得将参考图作为原创游戏素材打包。

## 2026-10-06：首版战斗框架与五只伙伴实施授权

来源：用户明确要求“开始用 subagent 的方式推进实施”，指定“实施用 astra-中，验收由你来”，目标是完成初版战斗框架与五只完整 Crashmon，其中三只初始三选一、两只野生，每只都有完整设计。

据此使用 Astra、中等推理的 subagent 分工实施纯内核/内容、后端资产和前端；主 Agent 独立执行测试、API 路径与浏览器验收。本轮范围为现有 Node.js 内置模块和 SQLite 下的本地 PvE，不授权部署或修改生产存档。三只初始保留 starter_a/b/c ID，两只野生使用 wild_scout/wild_shell；已有实例兼容迁移。

为了闭合本地试玩，实施采用显式一次领取 10 基础球、3 恢复药，以及普通和首领胜利按配置补 1 基础球；教学只允许每账号一次成功保护，任何教学结算不发球或经验。这些是本轮原型实施选择，正式经济仍待确认。当前固定基础值，经验仅记账，没有升级进化；首领建议 3–4 只挑战。完整野外暂以遭遇卡片入口替代，完整区域旅程仍未实现。

实现职责见[战斗框架](../architecture/battle-framework.md)，主 Agent 证据与未验收范围见[本轮验收](../verification/battle-2026-10-06.md)。独立验收不能代替人类对平衡与乐趣的判断，也不把完整 B01–B30 清单标为全部通过。
